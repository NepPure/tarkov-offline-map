服务端是自建的（仓库 server/ 目录，一条 docker compose 起服务）。 位置是"你按 Print Screen 那一刻"的定位，所以队友看到的是你最近一次截图的位置与去向。

目录

定位与显示

地名文字是"白色内色 + 深色外框"（先描边后填充，笔画平滑），默认已比旧版大；嫌挡地图就调小。

任务标记

任务数据是离线快照（data/quests-dump.json，来自 tarkov.dev）， 在你的电脑上按商人 → 阶段分组；勾选的任务才会把区域画到地图上（实线多边形＝任务区域，虚线小圈＝任务物品刷新点）。 勾选状态按存档长期保留，换图不丢。要更新数据就重新跑 npm run fetch:quests。

提示与行为

圆形小地图雷达

雷达默认没有任何按钮：按住圆盘任意位置即可拖动窗口（位置自动记忆），滚轮缩放， Ctrl + 拖动 = 平移圆盘里的地图（窗口不动；玩家照旧跟随，只是不再固定在圆心）， Ctrl + 双击 把视野偏移归零（换图时会自动归零）； 方向/居中/楼层/点击穿透/透明度都在这里调。开了点击穿透后，雷达右下角会出现一个小"解锁"块， 鼠标悬停到它上面时会临时恢复交互，点一下就关掉穿透（穿透状态下收不到鼠标，所以要先解锁才能拖动）。

关于

塔可夫地图 v-

《逃离塔科夫》的第三方地图辅助工具：读游戏日志识别你在哪张图，读截图文件名定位你的位置与朝向， 离线查阅撤离点、Boss、钥匙锁、物资箱、赛季文件刷点与任务目标，并可选地和队友开一个房间， 互相看到彼此的位置与标注。

  • 日志识图：自动识别当前地图，进图 / 过图自动切换，认错了也能手动选图
  • 截图定位：游戏中按 Print Screen，地图上立刻标出位置、朝向与移动轨迹
  • 悬浮小地图：可拖动的圆形雷达置顶在游戏画面上，滚轮缩放、Ctrl 拖动平移、支持点击穿透
  • 标记与图例：撤离点 / 转移点 / Boss / 出生点 / 钥匙锁 / 物资箱 / 地名 / 赛季文件刷点，右侧图例逐项开关
  • 任务清单：搜索勾选任务，把目标地点画在地图上，点标记看商人、等级、阶段、任务物品与所需钥匙
  • 手动标注：画圈、规划路径、箭头、矩形，按地图保存（存世界坐标，缩放旋转都不跑位）
  • 房间联机（v2.0 新增，可选）：填自己的服务器地址，和队友互相看到位置、朝向与标注
开源地址 github.com/NepPure/tarkov-offline-map

默认不联网：程序本身不发送任何请求，只有你在设置里填写了房间服务器地址后才会连接它。 本项目与 Battlestate Games 无关，地图与物品数据来自社区。
